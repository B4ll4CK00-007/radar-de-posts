Política de Privacidade

Última atualização: 6 de novembro de 2026.

1. Quem é o controlador

Lucas Digital, com sede em Rio de Janeiro, RJ, CEP 21550-370, Brasil, é a controladora dos dados tratados por esta aplicação. Contato: lucasdgtl11@gmail.com.

2. Que dados o app acessa

O Radar de Posts é uma ferramenta interna, executada pela equipe da Lucas Digital, que usa a API do Instagram (Instagram Graph API) para:

  • ler os dados públicos do perfil da conta profissional do Instagram do operador (identificador, nome de usuário, número de seguidores);
  • ler as publicações dessa conta (legenda, data, link permanente e tipo de mídia);
  • ler as métricas de engajamento das publicações (número de comentários, curtidas e visualizações);
  • consultar, pelo endpoint Business Discovery, o mesmo conjunto de métricas públicas de outras contas do Instagram do tipo Business ou Creator, quando o operador solicitam expressamente essa comparação.

O app não acessa mensagens, contatos, lista de seguidores, localização, e-mail, número de telefone, histórico de navegação nem qualquer dado privado. Ele não publica, não edita, não comenta e não remove conteúdo.

3. Finalidade e base legal

Os dados são tratados para medir o desempenho do próprio conteúdo e realizar comparativos de mercado com métricas públicas, com a finalidade de orientar decisões de conteúdo e de campanha. A base legal é o legítimo interesse da Lucas Digital (melhoria de conteúdo próprio) e, no caso de dados de terceiros expostos publicamente pela Meta para fins de benchmark, o interesse legítimo em informação pública de negócios.

4. Onde os dados ficam

Os dados lidos são gravados localmente, em um arquivo JSON na máquina de quem executa o comando. Não há banco de dados, não há servidor de aplicação e não há transferência de dados para terceiros. O token de acesso à API é gerado no painel da Meta e mantido em um arquivo .env local, excluído do controle de versão.

5. Compartilhamento

Não compartilhamos dados com terceiros. A Meta é a única parte que recebe os dados, por meio da própria API oficial, no âmbito da execução da consulta.

6. Retenção

Como não há armazenamento central, os dados duram apenas o tempo em que o arquivo JSON local permanece no dispositivo. A exclusão é imediata pela remoção do arquivo.

7. Direitos do titular

Para exercer os direitos de acesso, correção, portabilidade, anonimização ou eliminação de dados, escreva para lucasdgtl11@gmail.com. Para dados publicados pela Meta, o pedido também pode ser dirigido à própria Meta. Detalhes do procedimento de exclusão estão na página de exclusão de dados.
